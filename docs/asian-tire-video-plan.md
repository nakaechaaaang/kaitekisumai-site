# アジアンタイヤ解説動画 構成案・素材ガイド

> **目的**: 自社サービス（タイヤ販売・取付など）への集客
> **形式**: AI音声ナレーション＋テロップ（顔出しなし）
> **尺**: 約10分／本
> **予算**: 1本あたり 約25,000円
> **方針**: アニメーションは極力作らず、フリーの映像・画像素材＋テロップ＋簡単なモーションで仕上げる

---

## 1. このシリーズの作り方（低工数・低予算の前提）

「2.5万円・10分・量産」を成立させる最大のコツは、**毎回イチから作らずテンプレ化する**ことです。

- **共通テンプレを1つ作る** … オープニング／テロップの色・フォント／字幕の位置／BGM／エンディング（CTA）を固定。2本目以降は中身を差し替えるだけにする。
- **映像は「魅せる」より「間を持たせる」** … タイヤそのもののドンピシャ映像はフリー素材に少ないため、**車・道路・整備工場・街・高速道路などのBロール**で画面をつなぎ、情報はテロップと音声で伝える。
- **静止画＋ゆっくりズーム（Ken Burns効果）** で動画尺を稼ぐ … 編集ソフトの標準機能だけで“動いている感”が出せる。
- **数字・比較はテロップ図解** … 価格比較やメリット/デメリットは凝ったアニメではなく、文字＋アイコン＋四角の枠で十分伝わる。

### 1本あたりの想定コスト内訳（目安）
| 項目 | 内容 | 目安コスト |
|---|---|---|
| 構成・台本 | このテンプレに沿って執筆（または下記の台本を流用） | 0〜5,000円 |
| AI音声ナレーション | VOICEVOX等は無料／有料サービスでも月額数百〜千円 | 0〜2,000円 |
| 映像・画像素材 | 基本フリー素材で対応。足りない分だけ有料を購入 | 0〜8,000円 |
| BGM・効果音 | フリー音源で対応 | 0円 |
| 編集 | テンプレに流し込み＋テロップ（2〜4時間想定） | 残り（人件費/外注費） |
| **合計** | | **約25,000円に収まる** |

## 2. 標準構成（10分のタイムライン）

各ブロックに「話す内容」「使う素材」「素材の探し方キーワード」をセットで記載しています。
2本目以降はこの順番を崩さず、テーマだけ差し替えてください。

### ① オープニング／フック（0:00〜0:30）
- **内容**: 「アジアンタイヤって実際どうなの？安いけど大丈夫？」と視聴者の疑問をそのまま提示。今日わかることを3点予告。
- **素材**: 高速を走る車のBロール＋タイトルテロップ。テンプレ固定の冒頭。
- **検索キーワード**: `car highway driving`, `tire close up`, `車 走行`, `tire road`

### ② アジアンタイヤとは？（0:30〜1:30）
- **内容**: 中国・台湾・韓国・東南アジアなどで製造される低価格帯タイヤの総称であること。近年の品質向上の背景を簡潔に。
- **素材**: 世界地図の静止画（製造国をテロップでハイライト）、工場・製造ラインのBロール、タイヤ陳列の画像。
- **検索キーワード**: `tire factory`, `tire manufacturing`, `world map`, `tire shop shelf`, `タイヤ 製造`

### ③ メリット（1:30〜3:00）
- **内容**: ①価格が国産の半額前後 ②サイズ・銘柄のラインナップが豊富 ③日常走行レベルなら十分な性能、を順に。価格はテロップで「国産○○円 vs アジアン○○円」と並べる。
- **素材**: 価格比較テロップ図解（自作テロップ）、街乗りの車、買い物・通勤シーンのBロール。
- **検索キーワード**: `city driving`, `commute car`, `money saving`, `shopping car`, `節約`

### ④ デメリット・注意点（3:00〜5:00）★最重要・信頼の核
- **内容**: ①ウェット（雨天）性能やブレーキ性能で上位国産に劣る場合 ②ロードノイズ（静粛性）③銘柄による当たり外れ ④寿命・経年。**ここを正直に語ることが集客動画の信頼につながる**。
- **素材**: 雨の路面・ワイパー、濡れたタイヤ、夜の走行のBロール。注意点はテロップ箇条書き＋アイコン。
- **検索キーワード**: `rain road driving`, `wet road`, `windshield wiper rain`, `night driving`, `雨 道路`

### ⑤ 国産との比較・実際の評判（5:00〜7:00）
- **内容**: 「どんな使い方なら国産、どんな使い方ならアジアンが正解か」を整理。価格・性能・安心感を3軸の比較表テロップで提示。
- **素材**: 比較表テロップ（自作）、整備工場・タイヤ交換作業のBロール、レビューを模した吹き出しテロップ。
- **検索キーワード**: `tire change garage`, `mechanic tire`, `auto repair shop`, `タイヤ 交換`

### ⑥ こんな人におすすめ／向かない人・選び方（7:00〜8:30）
- **内容**: 「街乗り中心・走行距離少なめ・コスト最優先の人に向く／高速多用・スポーツ走行・降雪地はよく検討を」。失敗しない選び方（信頼できる店で買う・製造年を確認・サイズを正しく）を提示。
- **素材**: 家族の車・ファミリーカー、駐車場、カレンダー（製造年の話）等のBロールと画像。
- **検索キーワード**: `family car`, `parking car`, `tire sidewall`, `calendar`, `ファミリーカー`

### ⑦ 安全に使うためのポイント（8:30〜9:30）
- **内容**: 空気圧チェック、定期点検、プロによる取付の重要性。ここから自然に自社サービスへ橋渡し。
- **素材**: 空気圧チェック、点検作業、ピットのBロール。
- **検索キーワード**: `tire pressure check`, `tire inspection`, `car maintenance`, `空気圧`

### ⑧ まとめ＋CTA（自社誘導）（9:30〜10:00）★毎回固定
- **内容**: 3点要約 → 「タイヤ選び・取付で迷ったら当社へ。○○な方はお気軽にご相談ください」。概要欄・公式サイト・LINE等の導線を明示。
- **素材**: 自社ロゴ・店舗・スタッフ画像（自前素材）＋連絡先テロップ。**このエンディングはテンプレ化して全本共通で使う**。

### 補足
本構成案は「自社集客／AI音声＋テロップ」を前提にした汎用テンプレです。
以前お調べしたアジアンタイヤの調査メモ（具体的な銘柄名・価格・性能データ）をこのリポジトリ内に置いていただければ、③〜⑥の「話す内容」を実データに差し替えた**完成台本**まで作成できます。
