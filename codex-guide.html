CODEX GUIDE 初心者でもわかる Codex の使い方

Codex（コーデックス）とは？

むずかしい知識がなくても、文章でお願いするだけ。

Codex（クラウド版）は、ChatGPT の中で使える「AI のプログラミング担当者」です。あなたが日本語で「○○を直して」「△△を作って」とお願いすると、Codex がクラウド（インターネット上）の作業部屋でコードを書いたり直したりしてくれます。

自分のパソコンに特別なソフトを入れる必要はありません。ChatGPT の画面からお願いするだけで、Codex が裏側で作業し、その結果を見せてくれます。料理でいえば「材料と要望を伝えると、調理して仕上がりを出してくれるキッチン」のようなイメージです。

Codex でできること

こんな作業を、お願いベースで任せられます。

✏️

新しい機能をつくる

「お問い合わせフォームを追加して」のように頼むと、必要なコードをまとめて書いてくれます。

🐞

バグ（不具合）を直す

「ボタンが押せない不具合を直して」と伝えれば、原因を探して修正案を出してくれます。

❓

コードの中身を質問する

「このプログラムは何をしている？」と聞けば、内容をわかりやすく説明してくれます。

🧪

動作チェックや整理

テストの実行やコードの整理（読みやすく書き直す作業）も任せられます。

はじめての使い方（4ステップ）

画面の流れにそって進めれば大丈夫です。

1

ChatGPT で Codex を開く

ChatGPT にログインし、画面の横にあるメニューから Codex を選びます。Codex は対応プランで利用できる機能です（プランによって使える範囲が異なります）。

2

GitHub とつないで、作業するリポジトリを選ぶ

Codex は「リポジトリ」（プログラムの保管場所）の中で作業します。初回は GitHub アカウントを連携し、作業したいリポジトリを選びましょう。一度つなげば次回からは選ぶだけです。

3

やってほしいことを日本語で書く

入力欄に「○○ページを追加して」など、お願いを文章で書きます。変更を頼むときは Code、質問だけのときは Ask を選ぶと、目的に合った動きをしてくれます。

4

結果を確認して取り込む

Codex が作業を終えると、変更した箇所の一覧（差分）を見せてくれます。内容を確認し、問題なければ「プルリクエスト」という形で正式に反映します。気になる点は追加でお願いして直してもらえます。

上手にお願いするコツ

伝え方を少し工夫すると、ねらい通りの結果になりやすくなります。

✓

具体的に伝える：「よくして」より「文字を大きく、色を緑にして」のように、どうしてほしいかを書きましょう。

✓

場所を教える：「トップページの問い合わせボタン」など、対象のファイルや画面を示すと迷いません。

✓

一度に欲張らない：大きなお願いは小さく分けると、確認しやすく失敗も減ります。

✓

仕上がりの条件を添える：「スマホでも崩れないように」など、満たしてほしい条件を書くと安心です。

使うときの注意点

便利ですが、最後は人の目で確認することが大切です。

ここをチェック！

  • 結果は必ず内容を確認してから反映しましょう。間違いが含まれることもあります。
  • パスワードや個人情報など、見せたくない情報は入力しないようにしましょう。
  • 大事なデータは、反映する前にバックアップ（控え）をとっておくと安心です。
  • わからない言葉が出てきたら、その場で Codex に「これは何？」と質問できます。
